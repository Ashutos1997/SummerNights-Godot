## 주요 특징

* **아케이드 냉각 액션:** 제한 시간이 끝나거나 열기가 100%에 도달하기 전에 태양을 식히세요. 지속적인 분사로 콤보 배율을 최대 3.0배까지 쌓아 빠른 점수 획득과 궁극기 충전을 노릴 수 있습니다.
* **전략적 특수 기술:** **얼음 폭발(`R`)**로 열기 회복과 태양 이동을 일시 정지시키거나, 화면 전체를 정리하는 **카타스트롬 궁극기(`F`)**로 태양을 바다에 내리꽂으세요.
* **6종의 해제 무기:** 슬로우 모션 무기 휠(`TAB`)을 통해 치명타 특화 정밀 스트림부터 포격 및 근접 참격 모드를 지원하는 신성의 **구미호 버스터 IX**까지 다양한 블래스터를 활용하세요.
* **역동적인 위협 및 보스전:** 공중에서 태양 플레어를 요격해 물통을 즉시 보충하고, 태양풍 돌풍을 극복하며, 신기루의 오버실드와 다단계 보스 패턴을 격파하세요.
* **게임 모드:** 6개 스테이지로 구성된 일반 모드 캠페인을 공략하거나, 보스 웨이브 후 로그라이트 퍽 드래프트가 제공되는 무한 모드에서 한계에 도전하세요.
* **감각적인 레트로 그래픽:** 로우폴리 3D 비주얼, 절차적 바다 물결, 커스텀 GLSL 하늘/열기 셰이더, 레트로 CRT/PS1 필터 및 다양한 접근성 옵션(게임패드 지원, 고대비, 모션 감소)을 제공합니다.

## 조작법

| 입력 | 동작 |
|---|---|
| 마우스 | 물 대포 조준 |
| 좌클릭 (유지) | 물 분사 |
| 우클릭 / R | 얼음 폭발 발사 (충전 시) |
| F | 카타스트롬 궁극기 사용 (100% 충전 시) |
| Tab (유지) | 무기 선택 휠 열기 |
| ESC | 일시정지 / 설정 |

---

## 실행 방법

1. **Godot Engine 4.7.1** (stable) 실행
2. 프로젝트 관리자에서 **가져오기**를 클릭하고 `project.godot` 선택
3. **가져오기 및 편집** 클릭 후 **F5** 키를 눌러 실행

## 프로젝트 구조

```
SummerNights-Godot/
├── assets/          # 3D 모델, 텍스처, 사운드 효과음 및 셰이더
├── docs/            # 시스템 아키텍처, HUD 레퍼런스 및 패치 노트
├── scenes/          # 핵심 게임플레이, HUD 및 메뉴 씬
└── scripts/         # 게임 루프, 무기 메커니즘 및 게임 상태 관리
```
